## Abstract 💭
Wasp Detection aims to provide an architecture for efficiently labeling network packets in scenarios where inspecting every packet is impractical due to performance limitations
> This research work is based on Yisroel Mirsky’s paper [Kitsune](https://arxiv.org/abs/1802.09089) and its corresponding [repo](https://github.com/ymirsky/Kitsune-py)
